Ejercicio 2 — Identificar los tipos de datos
Observa este JSON:

{ 
    "nombre": "Carlos",
     "edad": 30, 
     "esEstudiante": false,
      "telefono": null 
}

Indica qué tipo de dato corresponde a cada valor:
1.
"Carlos" String (cadena de texto)
2.
30 → Number(Numero entero)
3.
false → Boolean
4.
null → null
Objetivo: distinguir String, Number, Boolean y Null.
